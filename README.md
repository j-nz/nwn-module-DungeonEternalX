## Resource policy

Ascension Island-owned NWScript source lives under `src/nss/` and is compiled with the module. Hak packages are restricted to supporting/client resources and must not contain `.nss`, `.ncs`, or `.ndb` by default. See [docs/Hak_Resource_Policy.md](docs/Hak_Resource_Policy.md).
